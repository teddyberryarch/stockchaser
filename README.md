# tebestck_bot — 레버리지 스윙 추적 봇 (yfinance)

야후 파이낸스로 하이닉스/샌디스크 본주를 5분마다 보고, 10거래일 고점 대비
낙폭이 -10/-20/-30% 닿으면 텔레그램으로 "○○○ 얼마어치 팔고/사라" 알림.
키·증권계좌 불필요. 자동주문 없음(알림만). 본장 기준.

## 왜 본주만 보나
- 레버는 본주를 2배로 추종 → 단계 판정은 본주 낙폭만으로 정확.
- 교체 '금액'은 레버 평가액을 본주 낙폭의 2배로 근사해서 제시(추정).
  정확한 금액은 알림 받고 토스에서 확인하면 됨. 비중 %는 통화 무관 동일.

## 채울 것
1) 환경변수 2개 (Railway Variables / .env)
   - TG_TOKEN  : BotFather 토큰 (노출됐던 건 /revoke 후 새 토큰)
   - TG_CHAT_ID: 7958777842
2) main.py POOLS — 거래할 때마다 갱신
   - spot_shares : 현물 주수
   - lev_ref     : 최근 레버 평가액(현재가×주수)
   - spot_ref    : lev_ref 적은 시점의 본주가 (레버 추정 기준점)

## 야후 티커
- 하이닉스 000660.KS / 샌디스크 SNDK (둘 다 확실)
- 레버(TIGER/TRADR)는 야후 조회 안 함 → 신생 종목 데이터 걱정 없음

## Railway
- 폴더 푸시 → Variables 입력 → 서비스 타입 Worker(Procfile)
- 로그에 [hynix]/[sandisk] dd/tier 찍히면 정상

## 명령
